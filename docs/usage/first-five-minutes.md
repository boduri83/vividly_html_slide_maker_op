# Vividly로 첫 자료 만들기 · 5분 안내

**설치형·쇼케이스 베타 `v0.24.0-beta.5` · Windows x64**
앱 버전: `0.24.0-desktop.5` · 슬로건: **Present Vividly.**

움직이고 반응하는 자료를 살펴본 뒤 내 발표로 바꾸어 보세요. **일반 편집·저장·발표에는 AI 로그인, Codex 설치나 API 키가 필요하지 않습니다.**

## 1. 설치하고 쇼케이스 열기

[Vividly 시작 페이지](https://boduri83.github.io/vividly_html_slide_maker_op/start.html)에서 **Windows 설치 프로그램**을 받습니다. `Vividly-0.24.0-beta.5-Setup-x64.exe`를 실행해 현재 사용자 계정에 설치하고, 시작 메뉴의 **Vividly**를 엽니다. 관리자 권한은 필요하지 않으며 바탕 화면 바로가기는 선택할 수 있습니다. 설치 없이 사용하려면 같은 페이지의 포터블 ZIP을 새 폴더에 모두 풀고 `Vividly.exe`를 실행하세요.

첫 실행에서는 **「SIGNAL TO SPECTACLE」 7장 쇼케이스**가 열립니다. 왼쪽 슬라이드 목록으로 원하는 장을 고르고 상단 **슬라이드 쇼**로 모션·버튼·키보드 동작을 살펴보세요.

| 장 | 살펴볼 표현 |
|---|---|
| 1 · 표지 | 큰 글자, V 심벌, 겹쳐진 색과 등장 모션 |
| 2 · 데이터 | 예시 데이터를 표시하는 차트와 숫자 |
| 3 · 디자인 | 그라데이션과 여러 개체를 겹친 CSS 디자인 |
| 4 · 선택 | 세 가지 버튼을 눌렀을 때 바뀌는 내용 |
| 5 · 플레이 | `1`·`2`·`3` 키 또는 체크포인트 버튼에 반응하는 화면 |
| 6 · 에디토리얼 | 글자와 개체를 잡지처럼 배치한 구성 |
| 7 · 클로징 | 발표를 마무리하고 표지로 돌아가는 동작 |

선택·키보드 동작은 **발표 모드**에서 사용합니다. 편집 모드의 클릭은 개체를 선택하는 작업입니다. **Esc**로 발표를 마치고 편집 화면으로 돌아오세요.

## 2. 제목과 도형 고치기

1. 첫 장의 큰 **Vividly** 제목을 **두 번 눌러** 내 제목으로 바꿉니다. 편집을 마치면 **Esc**를 누릅니다.
2. 오른쪽 **V 심벌**을 한 번 눌러 선택하고 드래그해 위치를 바꿉니다. 선택 테두리의 모서리를 드래그하면 크기를 바꿀 수 있습니다.
3. 마음에 들지 않으면 **Ctrl+Z**로 실행 취소하고 **Ctrl+Y**로 다시 실행합니다. 겹친 개체는 우측 **레이어**에서 개별 선택할 수 있습니다.

예제는 장 전체를 한 장의 그림으로 만든 파일이 아닙니다. 글자·도형·차트와 설정된 모션·동작을 각각 수정할 수 있습니다. 슬라이드 안의 제목과 앱 상단의 자료 이름은 별개이므로 저장할 자료 이름도 필요에 맞게 바꾸세요.

## 3. 차트와 반응 살펴보기

왼쪽에서 **두 번째 슬라이드**를 선택하고 차트를 두 번 누릅니다. 데이터 표의 **2월 `165`를 `190`으로 바꾼 뒤 `데이터 적용`**을 누르세요. 차트 변경도 Ctrl+Z 한 번으로 되돌릴 수 있습니다. 원래 값은 1월 `120`·2월 `165`·3월 `210`·4월 `280`이며 실제 사업 성과가 아닌 **사용법을 보여주기 위한 예시 데이터**입니다.

다시 **슬라이드 쇼**를 열고 네 번째 장의 선택 버튼 세 개를 눌러 보세요. 다섯 번째 장에서는 `1`·`2`·`3` 키나 화면의 체크포인트 버튼을 사용해 반응을 확인합니다. 직접 동작을 바꾸고 싶으면 Esc로 돌아온 뒤 개체를 선택하고 **인터랙션** 탭에서 연결을 살펴보세요. **애니메이션** 탭에서는 모션을 다듬을 수 있습니다.

## 4. HTML로 저장하고 다시 열기

**Ctrl+S**를 누르고 `우리 팀의 첫 자료.html`처럼 이름을 정해 저장합니다. 이 HTML에 편집 가능한 개체와 발표 화면이 함께 들어갑니다.

이어서 **Ctrl+O**로 방금 저장한 HTML을 엽니다. 글자 하나를 더 고친 뒤 Ctrl+S를 눌러 보세요. **Vividly가 저장한 HTML은 다시 열어 계속 편집할 수 있습니다.** 작업 원본을 남기려면 전달할 파일은 다른 이름으로 저장해 두세요. 앱의 **도움말 → 예제 처음부터 열기**로 쇼케이스를 다시 열 수도 있습니다.

## 5. 발표하고 공유하기

상단 **슬라이드 쇼**를 눌러 일곱 장의 모션·차트·선택 버튼·키보드 반응을 확인합니다. 예제의 이동 버튼 또는 발표 이동 도구로 장을 넘기고, 마지막 장에서 표지로 돌아갈 수 있습니다. **Esc**를 누르면 편집 화면으로 돌아옵니다.

저장한 HTML을 브라우저로 열어도 발표할 수 있습니다. 다른 사람에게는 HTML 파일을 보내면 됩니다. 받는 사람이 Vividly에서 열면 개체별 편집도 가능합니다. 전달 전에 포함한 자료와 글꼴·배치를 확인하세요. 글꼴은 환경에 따라 대체될 수 있습니다.
