Vividly/첫 사용 안내

5분 시작 안내

첫 자료,
한 번 만들어볼까요?

예제의 제목을 내 이야기로 바꾸고,
직접 저장한 뒤 발표까지 이어가세요.

Windows 64비트용 공개 베타입니다. 기본 편집·저장·발표에는 AI 계정이나 API 키가 필요하지 않습니다.

처음부터 차례대로

1. 앱 실행2. 예제 열기3. 직접 편집4. 저장·재열기5. 발표·공유문제가 생겼다면

01설치하고, Vividly를 여세요.

Windows 설치 파일을 실행하고 안내에 따라 설치합니다. 현재 사용자 계정에 설치되며, 완료 후 시작 메뉴에서 Vividly를 여세요. 바탕 화면 바로가기는 선택할 수 있습니다.

Windows용 설치 ↓설치 없이 ZIP으로 사용릴리스 안내·파일 해시

개발자 서명이 없는 베타이므로 Windows에서 경고가 표시될 수 있습니다. 공식 릴리스의 파일명·버전·해시를 확인하세요. 일반 앱 실행에 Node.js·개발 서버·별도 브라우저 설치는 필요하지 않습니다.

ZIP을 선택했다면 압축을 모두 새 폴더에 풀고 Vividly.exe를 실행하세요. 설치형은 Windows의 설치된 앱에서 제거할 수 있으며, 작성한 문서·복구본·개인 설정은 보존합니다.

027장 쇼케이스를 열어보세요.

첫 실행에서는 7장 쇼케이스가 열립니다. 네온 그래픽·모션·차트·선택 버튼·키보드 동작까지 모두 앱의 편집 가능한 개체로 구성했습니다. 다시 받고 싶다면 아래 HTML을 내려받고 Vividly에서 Ctrl+O를 누르고 받은 파일을 선택하세요. 화면에 보이는 글자와 도형을 그대로 편집할 수 있습니다.

편집용 예제 HTML 받기 ↓브라우저에서 먼저 보기 ↗

빈 화면에서 시작하고 싶다면 앱의 새 자료에서 시작하세요. 처음에는 예제를 한 번 바꿔보는 것만으로도 편집과 발표 흐름을 익힐 수 있습니다.

03제목과 개체를 내 자료로 바꾸세요.

  1. 제목을 두 번 누르고 원하는 문장으로 바꿉니다. 편집을 마치면 Esc를 누르세요.
  2. 도형을 선택해 드래그로 이동하고 모서리 핸들로 크기를 조절합니다. 홈 메뉴에서 채우기·테두리·글자색을 바꿔보세요.
  3. 한 번 되돌려 보고 싶다면 Ctrl+Z, 다시 반영하려면 Ctrl+Y를 누릅니다.

연결된 컴포넌트는 묶음으로 움직입니다. 안쪽 글자나 도형만 바꾸려면 레이어에서 개체를 따로 선택하세요. 예제에 있는 버튼과 모션도 발표에서 확인할 수 있습니다.

04다른 이름으로 저장하고 다시 여세요.

Ctrl+Shift+S로 내 첫 자료.html처럼 새 이름을 붙여 저장합니다. 이어서 Ctrl+O로 그 파일을 다시 열어 방금 바꾼 내용을 확인하세요.

다시 연 자료의 글자와 개체도 추가로 수정할 수 있습니다. 이후에는 Ctrl+S로 저장하세요.

저장 실패가 표시되면 앱을 닫기 전에 다른 이름·다른 폴더로 저장해 보세요. HTML 열기·저장 한도는 100MiB이며 동반 소스도 포함됩니다. 원본 파일과 복구 데이터를 먼저 지우지 마세요.

05발표하고, HTML을 열어보세요.

앱의 슬라이드 쇼를 누릅니다. 차례로 7장을 넘기며 등장·궤도 모션을 보세요. 선택 화면에서 버튼을 눌러 문구를 바꾸고, PLAY 화면에서는 1·2·3 키나 체크포인트 버튼으로 신호를 이동시켜 보세요. Esc로 발표를 마칩니다.

저장한 HTML은 브라우저에서도 발표할 수 있습니다. 편집을 이어가려면 Vividly에서 다시 열면 됩니다.

공유 전 확인: 편집용 HTML에는 화면 내용 외에 편집 데이터·저자 초기값·발표 메모·사용하지 않는 자산이 남을 수 있습니다. 민감한 내용이 없는지 확인하고, 필요한 경우 내보내기의 노트 포함 여부를 확인하세요. HTML 공유와 데이터 안내

막힌 지점을 알려주세요.

사용한 버전, Windows 환경, 재현 순서와 기대한 결과를 적어주세요. 원본 자료를 첨부하지 않고 가상의 내용으로 설명해도 됩니다.
